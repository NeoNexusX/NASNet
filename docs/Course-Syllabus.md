**当前进度：第 1 课已完成，第 2 课进行中，第 3～12 课为后续规划。** 原来的前三个小节已经完成；独立 NFS/SMB 校验仍是第 2 课后半部分的练习。

## 每课的学习和实现范围

### 第 1 课：设备模型、所有权、查询与排序

- **Rust 知识**：struct、impl、String、Vec、移动、共享/可变借用、Option、迭代器与闭包。
- **项目实现**：完成设备和地址的创建、添加、计数、改名、查询与稳定优先级排序。
- **你来写**：亲写模型方法、借用查找和引用列表排序；解释数据归属及可变性。
- **完成标准**：空列表和不存在的 ID 可处理；同优先级稳定；原保存顺序不变。
- **合并来源**：原第 01～02 学习单元。

### 第 2 课：错误处理与独立 NFS/SMB 配置

- **Rust 知识**：enum、Result、?、单元类型、带数据枚举、借用匹配、`Option<String>` 与切片。
- **项目实现**：完成 Host/地址校验、重复 ID 检查、独立协议配置、协议分派和连接保存。
- **你来写**：亲写两种协议的配置校验与枚举分派；按成功后才修改列表的顺序处理。
- **完成标准**：错误原因明确；失败不改列表；NFS/SMB 身份独立，连接列表只读借用。
- **合并来源**：原第 03～04 学习单元。

### 第 3 课：模型封装、生命周期与配置序列化

- **Rust 知识**：模块可见性、私有字段、构造与修改方法、借用返回值、生命周期基础、派生 trait 与 Serde。
- **项目实现**：统一设备/地址/连接的合法创建和更新入口，设计保存数据并实现序列化与恢复。
- **你来写**：亲写构造/更新/删除接口、数据转换与反序列化后的校验；按需练习基础泛型。
- **完成标准**：公开接口不能绕过校验；还原配置仍检查规则；ID、关联和顺序保持一致。
- **合并来源**：原第 05～06 学习单元。

### 第 4 课：SQLite、系统凭据与配置闭环

- **Rust 知识**：存储 trait、外部依赖、错误转换、SQL 参数与事务、文件路径及外部 API 封装。
- **项目实现**：保存和加载设备、地址、协议配置，对接系统凭据存储，形成重启可恢复的配置流程。
- **你来写**：亲写存储接口的关键实现、事务保存/加载和凭据引用的创建/读取/清理流程。
- **完成标准**：配置跨重启恢复；失败不留下半份配置；密码不进入普通配置和日志。
- **合并来源**：原第 07～08 学习单元。

### 第 5 课：C FFI、指针与资源安全封装

- **Rust 知识**：C ABI、`extern "C"`、裸指针、unsafe、CString/CStr、NonNull、Drop 与 RAII。
- **项目实现**：先完成小型 C 调用，再将创建/使用/关闭句柄封装成安全的 Rust 接口。
- **你来写**：亲写字符串转换、返回值检查、句柄构造和 Drop；说明每块内存的归属与有效期。
- **完成标准**：错误和提前返回路径正确释放；无双重释放或悬空访问；unsafe 边界清晰。
- **合并来源**：原第 09～10 学习单元。

### 第 6 课：真实 NFS 与 SMB 协议接入

- **Rust 知识**：原生依赖构建、绑定、协议适配、业务错误转换、凭据获取与句柄所有权。
- **项目实现**：固定并构建 libnfs/libsmb2，分别连接真实导出和共享，读取目录并释放资源。
- **你来写**：亲写关键连接调用、配置到后端的转换、目录结果转换与失败清理。
- **完成标准**：两种协议分别在真实 NAS 验证；配置和身份不混用；错误保留真实原因。
- **合并来源**：原第 11～12 学习单元。

### 第 7 课：统一远程能力与异步调用

- **Rust 知识**：业务 trait、统一数据结构、能力表达、async/await、线程、通道及 Send/Sync。
- **项目实现**：统一目录/文件/权限元数据接口，按能力提供权限操作，并建立异步调用与 C 上下文调度边界。
- **你来写**：亲写公共操作接口、协议适配、异步请求转交和结果返回；明确 C 上下文的拥有者。
- **完成标准**：调用界面无需硬编码协议差异；不支持的能力明确报告；C 上下文不被无依据地并发共享。
- **合并来源**：原第 13～14 学习单元。

### 第 8 课：会话管理、取消与地址故障切换

- **Rust 知识**：状态枚举、消息传递、按需使用 Arc、取消、超时、重试与错误传播。
- **项目实现**：管理连接生命周期，支持取消与安全关闭，按稳定优先级选择地址并处理失效重连。
- **你来写**：亲写会话状态流转、取消清理、地址尝试和错误分类后的重试决策。
- **完成标准**：网络失败可换地址；认证/权限失败默认停止；健康会话保持地址；取消后资源正确释放。
- **合并来源**：原第 15～16 学习单元。

### 第 9 课：终端应用、独立后台与本地 IPC

- **Rust 知识**：参数输入、业务编排、进程边界、消息序列化、请求/响应与事件。
- **项目实现**：形成可用的终端版，再把连接和远程操作放入独立用户后台，通过本地 IPC 调用。
- **你来写**：亲写命令编排、消息处理、请求关联、错误响应和后台退出流程。
- **完成标准**：从保存配置访问真实 NAS；终端能浏览/读取/取消；客户端退出后后台按设计继续运行。
- **合并来源**：原第 17～18 学习单元。

### 第 10 课：Tauri/Vue 桌面与配置管理

- **Rust 知识**：Rust 命令接口、前后端数据类型、IPC 错误映射与表单校验对接。
- **项目实现**：建立桌面骨架，管理设备、地址顺序、独立协议配置及凭据引用。
- **你来写**：重点亲写 Rust 命令与后台业务接线、输入转换和错误映射；前端工程由助手协助搭建。
- **完成标准**：界面能完整保存和恢复配置；表单错误清楚；后台是业务数据的统一入口。
- **合并来源**：原第 19～20 学习单元。

### 第 11 课：远程浏览界面与系统挂载

- **Rust 知识**：后台事件、状态与取消、能力数据、平台 trait、cfg、系统 API/进程封装。
- **项目实现**：展示远程目录/文件/权限及连接状态，接入当前系统支持的挂载和卸载。
- **你来写**：亲写事件/操作状态处理、挂载适配接口和能力检查；协助验证界面与后台联动。
- **完成标准**：关闭窗口后后台仍工作；浏览与挂载分别管理；占用时明确报告，不自动强制卸载。
- **合并来源**：原第 21～22 学习单元。

### 第 12 课：自动恢复、跨平台打包与交付

- **Rust 知识**：后台生命周期、状态持久化、幂等恢复、条件编译、固定工具链与发布构建。
- **项目实现**：用户登录后自启、按配置恢复连接/挂载，整理原生依赖并打包目标平台版本。
- **你来写**：亲写启动恢复和幂等判断，处理重复启动/占用/失败；参与平台构建与实际验证。
- **完成标准**：不重复挂载；失败可解释；在可用目标系统验证安装/启动/退出，记录平台能力限制。
- **合并来源**：原第 23～24 学习单元。

## 协作与检查规则

- 每课覆盖更多内容，可以分多轮填写和检查；通常留 4～8 个关键实现，复杂集成课按接口分轮安排。已经完成的小节直接计入，不重做。
- 你主要编写模型规则、错误传播、协议适配、资源封装和关键业务流程；助手提供必要的构建接线、重复调用和展示代码。桌面阶段仍以 Rust 接口和业务实现为学习重点。
- 检查通过后清理对应源码和演示中的学习提示、题号与过时进度说明，保留必要接口约束、讲义，以及 `main.rs` 中的长期课程表。
- 不自动重新增加课程测试文件，使用格式/静态检查、演示和明确的预期结果检查行为；真实协议、取消、挂载与打包需要在服务器和目标系统验证。
- 保持一个包，以模块划分职责；只有出现独立构建或复用需求时再调整。原生协议仍使用 libnfs/libsmb2，不改变已经确定的方案。
- NFS/SMB 权限操作以锁定库版本、服务器授权和目标系统能力为准；能力不足时明确报告，不把能编译当成实际支持。

12 课表示 12 个较完整的功能单元，不限定为 12 天。项目未使用的高级泛型、宏开发或底层优化按需补充，不另外扩充课程总数。
