## 运行入口与协作规则

```sh
cargo run --locked -- course01
cargo run --locked -- course02
cargo run --locked -- course03
cargo run --locked -- course04 --intro
cargo run --locked -- course04
```

前三课分别运行 A/B 两段，默认 `course01`。旧 `lesson01/02` 对应 01 A/B，`lesson03/04` 对应 02 A/B，`lesson05/06` 对应 03 A/B；旧 `lesson04` 与新第 04 课不同。`course04 --intro` 只运行 A 部分日志演示；`course04` 运行完整 A/B，在填写前会停在 TODO 4.8；`course04 <directory>` 只加载主配置；追加 `<device-id>` 才读取选定设备文件。编译通过只表示框架成立。

每课采用先介绍、再读源码、再亲写、再预测验证、最后双项验收。新库先讲用途、版本/feature、最小用法与项目接入点。助手写的代码必须有阅读归属；已经验收的功能不要求重写。第 04 课保留 1 项 TOML 入门练习与 13 个函数实现，后续按完整功能单元安排，允许分多轮完成。

使用 Rust 2024 edition，一个 package 内 lib/bin 分工，模块同名文件与目录并列。错误全部集中在 error 模块，英文 Display 与事件文字；模型/配置/存储不打印，应用边界统一记录与展示。清理已完成实现的临时学习提示，保留必要契约与长期课程表。

不自动增加课程测试文件，也不以空测试表示验收；使用静态检查、演示与明确预期，真实协议/挂载/交付另需目标环境验证。12 课表示完整学习单元，不限定为 12 天；项目未需要的高级用法按需补充。
